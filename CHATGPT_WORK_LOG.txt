LIVE COLAB GENERATION TEST - 2026-08-24
================================================================================

The user ran videoAI.ipynb on a live Colab GPU runtime using the queued sample
request:

mode: text_to_video
prompt: A cat waving its tail, sitting on a wooden floor, natural lighting
320x240, 17 frames, 8 fps

Colab successfully completed the runtime/bootstrap stages and reached the real
ComfyUI generation API. The generation failed with HTTP 400 validation:

prompt_outputs_failed_validation
node 3 (KSampler)
input "steps"
received "randomize"

ComfyUI reported that "randomize" could not be converted to INT.

ROOT CAUSE
================================================================================

The failure is in the repository's UI-workflow-to-API conversion, not GPU
availability or the trigger queue.

The official Wan 2.1 workflow stores KSampler widgets as:
[seed, "randomize", steps, cfg, sampler_name, scheduler, denoise]

Some current ComfyUI /object_info input_order responses omit the UI-only
control_after_generate widget. The previous converter therefore mapped:
seed -> seed
"randomize" -> steps   <-- WRONG
30 -> cfg               <-- shifted
6 -> sampler_name       <-- shifted
...

The current official workflow itself confirms the KSampler widget sequence,
including "randomize" immediately after seed.
