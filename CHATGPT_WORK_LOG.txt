================================================================================
NEW PROJECT DIRECTION - TWO SECTIONS
================================================================================

The project is now intentionally divided into TWO operational sections:

1. MAINLOAD
2. PORTABLE

These are not two unrelated applications. They are two deployment/runtime
modes sharing the same core OfflineMedia architecture where practical.

--------------------------------------------------------------------------------
1. MAINLOAD - LOCAL WINDOWS APPLICATION
--------------------------------------------------------------------------------

Purpose:
A downloadable application intended to run on a user's local PC.

Target environment:
- Windows PC
- Local CPU/GPU/RAM
- Local ComfyUI or another supported local generation engine
- Local AI models
- Local FFmpeg
- Offline operation after installation and required model assets are available

Mainload should eventually provide:
- Windows desktop GUI using PySide6
- Local model management
- Local workflow management
- Text -> Video
- Image -> Video
- Image Sequence -> Video
- Local project/history management
- Output preview
- Diagnostics
- Configuration
- Packaging/installer

Important:
Mainload must NOT assume that every local PC has a powerful NVIDIA GPU.
Hardware detection and capability reporting are required. The application
should tell the user what is actually possible instead of pretending that an
Intel integrated GPU is secretly an RTX 5090.

Mainload is the eventual end-user product.

--------------------------------------------------------------------------------
2. PORTABLE - GOOGLE COLAB / GPU DEVELOPMENT RUNTIME
--------------------------------------------------------------------------------

Purpose:
A portable development/testing environment intended primarily for Google
Colab, where NVIDIA GPU resources can be used for real AI video generation.

Target environment:
- Google Colab
- Linux runtime
- NVIDIA GPU when allocated by Colab
- ComfyUI
- Downloaded local AI models inside the Colab runtime/Drive as appropriate
- Repository cloned from GitHub

Portable should provide:
- One-command or minimal-step setup
- GPU detection
- ComfyUI setup/startup
- Required custom-node setup when needed
- Exact model/workflow installation
- Diagnostics
- Generation CLI/API
- Real text-to-video smoke test
- Real image-to-video smoke test
- Output validation
- MP4 preview/download from Colab
- Easy reset/rebuild of the runtime

Portable is NOT the final Windows application.
It is the real-GPU laboratory for validating the generation pipeline before
that pipeline is connected to Mainload.

================================================================================
SHARED ARCHITECTURE PRINCIPLE
================================================================================

Mainload and Portable should share the same core generation concepts wherever
possible.

Shared concepts:
- GenerationRequest
- GenerationType
- Workflow loading/validation/binding
- ComfyUI client
- Engine abstraction
- Model manifests
- Model verification
- Output/project metadata
- Diagnostics logic where platform-independent
- Tests

Platform-specific concerns should remain separated.

Example:

                    OfflineMedia Core
                           |
             +-------------+-------------+
             |                           |
         MAINLOAD                     PORTABLE
       Windows PC                    Google Colab
             |                           |
        PySide6 GUI                 CLI / Notebook
             |                           |
       Local ComfyUI               Colab ComfyUI
             |                           |
             +-----------+-------------+
                         |
                  Generation Engine
                         |
                    AI Workflows
                         |
                    AI Models
                         |
                       MP4

Do NOT duplicate the generation engine merely because the deployment target
is different.
