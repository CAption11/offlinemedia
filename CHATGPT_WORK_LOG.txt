3. Added portable/OfflineMedia_Portable_Colab.ipynb

Notebook flow:
- Detect NVIDIA GPU.
- Clone/refresh the active OfflineMedia branch.
- Install repository Colab dependencies and huggingface_hub.
- Clone ComfyUI and install its requirements.
- Download the official Wan 2.1 T2V 1.3B assets from the Comfy-Org
  repackaged model repository.
- Synchronize the current official T2V/I2V workflows.
- Start ComfyUI on 127.0.0.1:8188.
- Verify /system_stats.
- Load the official UI workflow through OfflineMedia's Workflow converter.
- Bind prompt, dimensions, frame count, FPS and seed.
- Queue the workflow through the shared ComfyUIClient/ComfyUIEngine stack.
- Download actual ComfyUI outputs.
- Convert a returned video output to MP4 using ffmpeg when necessary.
- Validate the MP4 with ffprobe and file-size checks.
- Display the generated video in Colab.

The notebook does NOT claim success without executing the real GPU/ComfyUI
pipeline.
