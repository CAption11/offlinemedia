1. .github/workflows/portable-trigger.yml

Purpose:
- Manual GitHub Actions trigger for Portable.
- Accepts mode, prompt, width, height, frames and fps.
- Creates a durable JSON request at portable/trigger.json.
- Pushes the request to the active branch.

This is intentionally a trigger/queue, not a claim that GitHub Actions can
magically execute a sleeping Google Colab session.

2. portable/trigger_listener.py

Purpose:
- Poll the GitHub Contents API for portable/trigger.json.
- Wait until a request has status=queued.
- Return the generation request to the running Colab notebook.
- Supports private repositories through a GitHub token supplied by environment
  variable GITHUB_TOKEN or GH_TOKEN.

3. portable/trigger_protocol.md

Documents the generic architecture and the Colab listener cell.

Architecture:

GitHub Actions
     |
     v
portable/trigger.json
     |
     v
running Colab notebook polls GitHub
     |
     v
OfflineMedia generation
     |
     v
ComfyUI + NVIDIA GPU

IMPORTANT LIMITATION:
Colab is not a permanent server. The notebook must already be running and
polling. If its session expires, the queued request remains in GitHub until a
new Colab session starts and reads it.
